## Known issues
- The default `python3` on this host is 3.7.6, and the vendored `sarc-governance` dependency still uses Python 3.10-only type syntax (`dict[str, ...]`), so the real-adapter script only runs end-to-end under `python3.10`.
- I added a compatibility shim for `typing.Protocol`, but the dependency has a separate `dict[str, ...]` incompatibility that remains upstream.
