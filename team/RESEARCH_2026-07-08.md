# Research Increment — 2026-07-08

## Objective
Tighten the paper’s positioning of `delegated_remediation_conflict` so the 10-scenario benchmark is consistently framed as a composition problem spanning ROMA-style delegation, AARM-style interception, async serialization, and deterministic conflict arbitration.

## Background
- The repo already contains the 10-scenario benchmark and the delegated-remediation case in `paper/07_evaluation.md` and `docs/evaluation-plan.md`.
- The current related-work text is close, but the narrative can still drift toward a SARC-only reading unless the hybrid case is called out explicitly.
- This matters because `delegated_remediation_conflict` is the clearest example where delegation lineage, step-up approval, and async control signals all appear together.
- The benchmark’s value is not just that the final verdict is `ESCALATE`; it is that the composed trace preserves both the step-up and serialization interventions.
- Related-work prose should therefore emphasize composition across heterogeneous runtime modules, not just runtime enforcement or delegation in isolation.
- The evaluation prose and the related-work matrix should agree on the same terminology so the builder does not have to reconcile divergent descriptions.
- The current blocker around evaluation-summary drift suggests this is a good moment to make the paper text and exported summary language line up with the current benchmark semantics.

## Proposed change
File-level update for the builder:

1. `paper/08_related_work.md`
   - Add or tighten a paragraph in the AARM / ROMA positioning so `delegated_remediation_conflict` is presented as a hybrid case combining delegation lineage, interception, async control, and arbitration.
   - Make the summary table explicitly say OpenClaw-Govern composes these layers rather than treating SARC as the only frame.

2. `docs/related-work.md`
   - Mirror the paper wording in the matrix so the summary notes mention ROMA-style delegation, AARM-style interception, and async serialization/conflict arbitration together.

3. `paper/07_evaluation.md`
   - Keep `delegated_remediation_conflict` as the canonical 10th scenario and ensure the trace-completeness sentence explicitly preserves both interventions plus the delegation lineage.
   - Keep the verdict order statement clear: `ESCALATE` dominates `SERIALIZE` for this case under the current composition semantics.

4. `docs/evaluation-plan.md`
   - Align the scenario description and expected outcome with the paper wording so the benchmark plan uses the same hybrid framing.

5. `results/generate_plots.py` and/or `results/EVALUATION_SUMMARY.md`
   - If the summary text is still hardcoded, derive the prose from the CSV-backed scenario names and outcome labels so the exported narrative cannot drift from the benchmark snapshot.
