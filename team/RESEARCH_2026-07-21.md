# Objective
Finalize the policy-laundering / provenance-retention increment so the paper treats sanitized-intermediate bypasses as a scored benchmark scenario, while keeping the novelty claim centered on composable runtime governance.

# Background
- The current queue item is the policy-laundering / prompt-injection-derived failure mode with provenance-retention scoring.
- The main research point is composition: a child agent, adapter, or summarizer can sanitize an unsafe request, but the governance layer still needs lineage across that boundary.
- This is not a prompt-injection-only story; it is about how runtime constraints, delegation propagation, async execution controls, and unified traces behave under sanitization pressure.
- The benchmark should preserve a clear distinction between verdict correctness and provenance recovery.
- A run can be “correctly denied” yet still fail the composition requirement if the original unsafe request is no longer recoverable in trace metadata.
- AgentArmor is the strongest precedent for turning runtime traces into structured security artifacts.
- AuthGraph is the clearest provenance-vs-authorization comparison at parameter-source granularity.
- VIGIL gives the verify-before-commit precedent for tool-stream injection and untrusted intermediate outputs.
- Trace-based assurance work reinforces contract-localized replay, governance evidence, and regression-style evaluation.
