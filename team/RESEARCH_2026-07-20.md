# Objective
Finalize the policy-laundering / provenance-retention increment so the paper treats sanitized-intermediate bypasses as a scored benchmark scenario, while keeping the novelty claim centered on composable runtime governance.

# Background
- The current queue item is the policy-laundering / prompt-injection-derived failure mode with provenance-retention scoring.
- The core research point is not prompt injection alone; it is how composition behaves when a child agent, adapter, or summarizer sanitizes an unsafe request and the governance layer must still preserve lineage across the boundary.
- This scenario should remain a benchmarked composition problem: ordered runtime modules, delegation propagation, async controls, and unified traces all need to stay visible.
- The evaluation text should distinguish verdict correctness from provenance recovery, because the laundering case can be “correctly denied” yet still fail if the original unsafe request is not recoverable in trace metadata.
- AgentArmor is the strongest precedent for turning runtime traces into structured graph artifacts for security analysis.
- AuthGraph is the clearest provenance-vs-authorization comparison, especially at parameter-source granularity under indirect prompt injection.
- VIGIL gives the verify-before-commit precedent for tool-stream injection and untrusted intermediate outputs.
- Trace-based assurance work reinforces contract-localized replay, governance evidence, and regression framing, which fits a provenance-retention metric.
