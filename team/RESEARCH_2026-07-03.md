# Research Increment — 2026-07-03

## Objective
Add a composition benchmark scenario that exercises delegated runtime governance when AARM-style interception, ROMA-style delegation, and conflict resolution all apply to the same action.

## Background
- The paper already argues that OpenClaw-Govern is the composition layer above SARC-style enforcement, not a SARC-only system.
- The current evaluation covers nine scenarios, but the failure taxonomy is still missing a case where a delegated subtask crosses a runtime interception boundary and produces a remediation-vs-denial conflict.
- ROMA is relevant because it gives recursive task trees, hierarchical traces, and heterogeneous orchestration, but it does not define arbitration across governance modules.
- AARM is relevant because it treats action execution as the security boundary and supports allow/deny/modify/defer/step-up decisions with tamper-evident receipts.
- OPA decision logs provide a strong precedent for exporting policy queries, inputs, bundle metadata, and audit-friendly decision records.
- XACML combining algorithms are the closest policy-combining precedent for deterministic arbitration semantics.
- The new scenario should stress ordered composition, not just one mechanism in isolation.

## Proposed change
Create a new bounded increment to add a 10th composition scenario, tentatively named `delegated_remediation_conflict`, that checks how the system resolves a delegated child action when:
1. the parent delegation cap allows the task shape,
2. AARM-style runtime interception wants `MODIFY` or `STEP_UP`,
3. async control wants `SERIALIZE`, and
4. the final composed verdict must be deterministic and auditable with complete trace evidence.

File-level proposal for builder:
- `paper/07_evaluation.md`
  - Add the 10th scenario to the benchmark list.
  - Define the expected verdict and the exact intervention ordering.
  - Extend the trace-completeness metric to require explicit representation of delegated remediation decisions.
- `docs/evaluation-plan.md`
  - Mirror the new scenario and spell out the expected ground-truth verdict.
- `paper/08_related_work.md` and `docs/related-work.md`
  - Strengthen the ROMA/AARM positioning language so the novelty reads as composed runtime governance across delegation, interception, and arbitration.
- `results/` outputs, if needed by builder
  - Regenerate benchmark summary tables and trace exports so the new scenario is reflected consistently.
